# 惊蛰 WebAR 真机验收清单

## P0：必须通过

- [ ] HTTPS 页面可正常打开，无证书警告。
- [ ] 首次点击后才请求摄像头权限。
- [ ] 拒绝权限时出现演示模式入口。
- [ ] A5哑光打印卡在25—45厘米距离可识别。
- [ ] 卡片轻微旋转时，AR场景跟随中心、尺寸和角度变化。
- [ ] 丢失卡片后场景消失，重新对准后恢复。
- [ ] 升温滑块达到阈值后进入春雷步骤。
- [ ] 春雷按钮产生画面反馈；不支持振动或声音时流程仍继续。
- [ ] 三候可依次或任意顺序解锁。
- [ ] 完成三候后可以进入记录页。
- [ ] 未选择观察或未填写城市时不能生成结果。
- [ ] 刷新页面不会出现摄像头持续占用。

## P1：提交前通过

- [ ] iOS Safari测试完成。
- [ ] Android Chrome测试完成。
- [ ] 微信内置浏览器测试完成；失败时有外部浏览器提示方案。
- [ ] 室内普通照明、靠窗自然光、展厅偏暗环境分别测试。
- [ ] 4G网络首次打开时间可接受。
- [ ] 竖屏小尺寸手机不遮挡关键按钮。
- [ ] 卡片文件按100%比例打印为A5尺寸。
- [ ] 录制一段不剪辑的完整真实操作视频作为技术证明。
